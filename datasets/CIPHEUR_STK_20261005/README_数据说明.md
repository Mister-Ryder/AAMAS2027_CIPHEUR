## 数据契约

每个候选是一次完整的卫星—地面站几何可见区间，收益为原端点差。每星、每站各一个通信通道。84 星、12 站，规划时域 72 小时，前后各传播 1 小时；跨规划边界的窗口单独保存，不能裁短后计入主数据。均匀相位 A-U 和成对相位 A-P 使用方案中逐星列出的初始轨道元素。

同一机会库的四个配置共享接触、资源及收益，仅地面切换间隔不同：340、680、1200、1800 秒。卫星间隔固定 150 秒。同资源按起点排序后，在后一个开始时刻严格早于前一个结束时刻加切换间隔时连冲突边；恰好相等时兼容，包含和同时开始均冲突。

STK 原报告保留原数值。求解用微秒整数 tick 固定数值实例；这不表示物理仿真的精度达到微秒，不能另行降低精度制造特征碰撞。收益始终由冻结端点相减，不重赋权。

## 推进规则

P0 先生成 4 个机会库、16 个配置图，并执行预先固定的查询。必须分开报告严格偏好、平局、未知、不可用，以及局部 patch 与全图证书的范围。原表示的精确矛盾需要在全部严格要求上按完整 base9 构造 quotient；配置反转、近似相同或结构可区分均不能代替该证据。

仅在文档规定的决策响应、信息必要性、实际执行敏感性形成实测联系后，进入 P1 小批量特征—规则合成。P2 在冻结后使用新的来源与未见配置。未满足条件时保留真实失败分支，按方案最多追加一轮开发几何轴，不能根据我方胜负筛选测试数据。

同一 r 编号的两种几何、全部 gap、子集和 patch 始终属于同一划分。日期与相位变化不自动证明统计独立；统计分析按物理来源组聚合。
