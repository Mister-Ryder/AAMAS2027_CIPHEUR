## 完整 base9 的精确结果

16 张完整图共有 199,528 个动作发生项，得到 199,528 个不同完整 base9 向量，精确非平凡碰撞类为 0。

不重复计算 gap 配置时，4 个库中有 16 个重复 duration 类，共 32 个接触发生项；重复 duration 仅是必要条件，没有产生完整全图碰撞。各库 n 为 12,465 / 12,467 / 12,471 / 12,479，完整空边界的 remaining_count 坐标可直接区分不同库；不同 gap 则由 station_gap 坐标区分。

此处命名空间是 `exact_microtick_base9_v1`，所有接触活动且 `F=X=∅`。实际执行头使用 Fraction 秒值与二进制 `fsum` 聚合时，必须使用独立命名空间 `fraction_seconds_binary_fsum_base9_v1`；两者的 equality 不混用。

以上结果严格限定完整图空边界。它不能排除同一 contact 在不同 restricted states 的向量再现，不能代替完整 strict demanded quotient，也不能单独决定 G2 失败。是否存在跨状态的非平凡有向环，须由证据组对实际边界的认证要求和完整精确连接计算。

## 接近切换阈值的数值诊断

16 图仅有两个同资源接触对满足 `|start_later-end_earlier-gap|≤0.002` 秒（包含原本不连边的情况）。这是诊断范围，Access Time Convergence 不当作物理误差界。

- CP-AP-r000 / g680：node1138→851，原余量 +0.001997 秒，兼容。独立 maxStep15 / convergence0.0001 计算得到 +0.001789571994 秒，仍兼容；冻结原数据不变，另见 `boundary_sensitivity/CP-AP-r000_g0680/result.json`。
- CP-AP-r001 / g1200：node884→5243，原余量 −0.000102 秒，冲突。独立 maxStep15 / convergence0.0001 计算得到 −0.00044295899 秒（细化微秒实例为 −443 tick），仍冲突；冻结原数据不变，另见 `boundary_sensitivity/CP-AP-r001_g1200/result.json`。负责人收到该结果后继续该来源标签计算。

两次针对性计算均未发生阈值符号翻转。这是给定参数细化下的数值稳定性观察，不是轨道或事件的严格物理误差界。

若数值细化改变阈值判定，应保留冻结数值图和原始证据的完整记录，并单列受该边影响的实际 query scope；不能把冻结数值实例的证书自动称为精确物理证书。
