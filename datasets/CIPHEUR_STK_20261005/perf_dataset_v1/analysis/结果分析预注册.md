# 完整算法比较：结果前分析注册

本文件在读取正式结果前确定口径。只分析总任务明确释放的冻结运行输出；不加载或评分 TEST 图，不运行求解器、STK、LLM 或条件完成值 oracle。正式结果到齐后生成 `完整LLM算法性能对比.md`、精确 CSV、失败记录和科研静态图。

主结果是完整可行调度时长，保留整数微秒奖励；与 Degree、CHILS population4/population1、CP-SAT 和同核经典头逐项配对。配对键为来源、配置、种子、声明 CPU 预算与输入图 SHA。预算为2/10 CPU秒，报告完整最终输出和实际总 CPU/墙钟/超预算量；不把预算后最终验证的完整结果伪装成硬截止结果。

独立统计单元是 r008、r009 两个物理来源组。组内种子、配置和 AU/AP 几何都是重复测量；按种子→配置→几何→来源组等权平均。每个来源组单独呈现；不将多个配置与种子伪作独立样本，不为 n=2 制造显著性或置信区间。两批 LLM 的全部冻结最终程序分别报告。

缺失与不可行质量为 NA，不用零填补。原生方法失败但共同核有可行回退时，保留回退质量并清晰列出原生失败。程序错误、deadline部分构造、guard拒绝、原始负gain、head从未提交和特征计算成本都保留；不能从可行核的保底质量推断合成程序的有效性。

配置按四个均匀间隔340/680/1200/1800秒和四个异质W/E间隔(1200,340)、(340,1200)、(680,1200)、(1200,680)划分。已见为A/W/E/J，新配置为680/680、1800/1800和两个680混合。均匀/异质与已见/未见是交叉描述维度，不能当作互斥总体相加。

统一图表方案：

1. 配置响应：两预算 × Degree/CHILS p4，正负差值统一零中心色标；每程序/批次逐配置展示，不只展示最优程序。
2. 质量与计算代价：实际 CPU 与完整质量差值、特征 CPU，小面板中保留来源组和两批标记。超预算不裁剪。
3. 真正 anytime：固定 AU-r008、seed2、W和未见(680,1200)两个配置，分别2/10秒；只画已观测的commit阶梯。CHILS只显示起终点标记，缺少内部trace是观测受限，不等于内部无进展，不据此宣称硬截止优于CHILS。
4. 训练证据链：冻结程序的严格TRAIN fit→完整TRAIN收益→完整TEST收益，固定2秒和匹配A/W/E/J配置。只作描述，不预设修复信息能带来排序或最终质量提升。

全零、饱和或只有起终点的结果用精确数值表与缺失原因解释；不制造曲线和中间数据。统一白底、英文科研图标、8pt字体、同arm颜色、batch0实心/实线、batch1空心/虚线，输出整图PDF/300dpi PNG及可由LaTeX独立排版的小面板PDF。图内只保留轴、单位、必要标记；论述放图注与报告。

分析入口位于第二篇 `experiments/stk_full_llm_v1/scripts/analyze_comparison.py`。前数据准备模式 `--prepare --self-test --output <本目录>` 不读取任何结果。正式模式要求显式 `--released-formal-results`、冻结protocol、冻结bank、各阶段的明确结果projection路径；完整TEST覆盖不足会停止，只有指定 `--allow-partial` 才能生成醒目标记为部分结果的报告。其输出不构成论文录用承诺。

CHILS使用SEA2025发表版及原始实现（population1/4均单线程）；CP-SAT引用CP2023发表介绍。Degree/weight/GRASP是同可行核中的经典head，local2swap是项目LS，不宣称完整原论文算法复现。全部微秒权重不round。具体出处与commit写入机器可读 `analysis_registration.json`。
