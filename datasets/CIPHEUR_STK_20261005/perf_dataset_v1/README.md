固定八个独立配置如下，卫星周转均为150秒。west 是经度88/94/100°的六站，east 是106/112/118°的六站，均跨两个纬度行。

- uniform：340、680、1200、1800秒，其中1800为压力配置。
- W/E：`(west,east)=(1200,340)`、`(340,1200)`。
- 未见混合配置：`(680,1200)`、`(1200,680)`。

异质框架的 A/J 分别引用 uniform340/uniform1200，不重复计入。`source_plan/perf_graph_parameters.json` 保存实际逐天线 gap 映射。图中的 `ground_gap_by_node_ticks` 和逐天线映射是运行时应读取的真实站间隔，不能用全局均值替代。

TEST 在所有评分程序冻结前仅允许物理生成、来源核验和输入图完整性检查。本流程不生成 TEST 决策证据、不进行调参、不调用优化器或 LLM，也不报告 TEST 启发式评分/调度质量。输入图检查不是算法有效性实验。

运行入口：`scripts/refresh_source_index.py` 更新本目录自己的物理完成索引；`scripts/build_perf_graphs.py --wait-for-ready` 在原物理库成功后生成新图。原物理入口仍为原数据根 `scripts/stk_generate.py --scene <已冻结场景ID>`，成功目录禁止覆盖。每次 STK 生成使用新的自有隐藏实例并仅关闭该实例。
