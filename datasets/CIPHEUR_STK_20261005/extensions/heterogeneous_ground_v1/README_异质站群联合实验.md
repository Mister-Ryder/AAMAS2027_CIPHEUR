# 异质资源配置的联合变化

本轮在2026-10-05用户授权的多配置复杂性扩展下开展。先前 `joint_resource_v1` 的sat150→600未改变可行集，已根据完整输入数学结果停止求解。本轮不提高无作用的卫星参数，而是让既有地面资源分别具有自己的配置。

## 配置与控制

按原站点经度预先固定两个资源操作组：西组88/94/100度，东组106/112/118度；每组6站。分组仅用于两个独立资源操作策略，不声称经度决定周转时间。全站仍为单天线，每星容量1，卫星间隔150秒。

| 配置 | 西组地面间隔（秒） | 东组地面间隔（秒） |
|---|---:|---:|
| A | 340 | 340 |
| W | 1200 | 340 |
| E | 340 | 1200 |
| J | 1200 | 1200 |

同一机会库的顶点、完整窗口、收益、轨道与站点保持一致。A/J分别是原均匀g340/g1200配置；W/E单独改变一个站群；A→J同时改变两个资源配置。两组各自新增边必须实际生效，不能只看参数表。

复用四个已完成的STK机会库与原扩展诊断30个注册patch/库的共同F/P/X。J与原g1200一致，因此外部调度和活动域也一致。所有patch、动作、各站gap映射及程序先保存后计算标签。旧标签不参与场景、查询或控制头选择；四侧条件值重新在共同2秒、八空间预算下计算。

## 表示与执行

完整base9仍保留九字段。`station_gap`明确表示当前根动作所属天线的实际间隔，采用每资源映射；其余八字段保持原语义。均匀配置是这一含义的特例。不能用平均值、最小值或虚构的全局常量代替实际gap。

为支持异质资源，单独提供station-local评分适配器，实际评分与证据phi必须一致；旧冻结程序表达式与修复核保留，旧源文件不修改。新数值namespace明确为`heterogeneous_station_local_base9_v1`。A/J的九字段和相同程序分数须与原均匀接口一致；adapter查读成本计入执行成本。

其他站群的约束可能改变远处补完结构，同时保持当前动作自身及一跳统计不变。这个性质是需要检验的结构信息需求，不能预先宣称其必然产生矛盾。

## 证据与停止标准

认证四侧条件偏好差Δ及交互量 `I=ΔJ−ΔW−ΔE+ΔA`。区间严格传播；只有四侧全部严格、A/W/E同向且J相反，才计作联合独有反转。六种配对关系由同一批证书导出，unknown/tie/unavailable完整保留。

实际B&B固定2000节点，pairwise commit单独标记；Degree、旧冻结控制及离线参考头共享边界与补完规则。成本和损失均报告。新旧所有严格要求仅在语义兼容后合并完整quotient，检测自环和循环。

仍是r000/r001两个TRAIN开发来源组；没有新独立物理样本、没有TEST曝光、没有在线或离线LLM提案。复杂度提高不自动触发P1，须先形成表示必要性和真实执行联系。

## 正式结果与入口

2026-10-05，16张异质配置图与四组服务器作业全部完成，四作业均exit=0。120个注册共同边界查询产生480个配置侧状态、1,440条B&B执行记录和1,440条commit诊断记录。没有新增LLM调用、VALIDATION或TEST曝光。

**本轮首次认证了完整base9的信息矛盾。** 225条新严格要求形成二环；与旧518条要求合并后，743条要求、970个表示类同样存在循环。主病例是 `CP-AU-r000:q008:d16`：东组两个候选在E/J下各自完整九字段相等，而严格偏好差从 +97.768692 秒变为 −423.700893 秒。边界F/P/X相同，活动域64个候选；该证明针对声明的条件补完问题。

全部228组“双候选九维输入同时相等”的配置配对中，94组严格保持、131组未知、3组严格反转。三个反转分布于r000与r001两个开发来源组，均在64节点活动域；不是独立TEST泛化证明。上限128的160个配置侧全部未知，反映本轮八个forced spaces共享总2秒的认证预算边界。

四侧全部严格的查询为41/120，联合独有反转为0/41；交互区间严格为负2/120、精确为零40/120、未知78/120。信息矛盾与联合独有反转是不同证据目标，不能相互替代。

实际执行保留负结果：旧冻结头相对Degree的B&B平均值差为−2.902786秒，111胜/115负/254平，操作量约9.415倍。离线认证参考在B&B的480状态全部同值；在带正收益接受保护的commit诊断中为43胜/0负/437平、平均+3.326189秒。这些结果没有证明新的LLM程序或完整72小时调度算法已获得优势。
