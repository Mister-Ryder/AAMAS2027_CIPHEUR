# 异质配置实验结果与下一步

**复杂性这次有帮助，但帮助首先体现在核心机制的数学证据上。** 异质站群干预首次产生了完整九字段表示无法同时满足的严格决策要求；原均匀约束实验没有观察到这一障碍。当前结果尚未证明大规模端到端调度优势，旧冻结头的平均收益仍为负且计算成本明显更高。本轮不追加证据预算，不启动新 P1 或批量 LLM。

**必须前置说明证据预算边界。** 每个四配置查询的八个 forced-inclusion 空间共享总计 2 秒，不是每个空间 2 秒。128 节点活动域的 40 个查询、160 个配置侧偏好全部为 unknown；不能称其已完整解决，更不能用它们声称大规模最优性或泛化效果。G2 主证据来自同一固定边界下的 64 节点活动域。

每源完整保留原预声明的 10 个锚点 × 16/64/128 三种活动域，共 120 个四配置查询，无 unavailable。共同 `F/P/X`、外部 J-Degree 调度及 a/b 均从旧的标签前 manifest 继承；本轮重新对称计算所有四侧证据，没有复用旧 A/J 标签或按胜负换例。

新增表示语义为 `heterogeneous_station_local_base9_v1`：`station_gap` 是根接触所属真实天线的 gap，完整当前图仍包含其他站群的约束变化。其余八字段与旧数值语义一致，A/J 均匀情况是旧接口的特例；没有用平均值、最小值或零替代异质约束。旧规则表达式和修复求解核保持冻结。新增局部字段读取在实际发生时计费。**本轮新 LLM 调用为 0。**

所有条件值均为固定外部承诺后，活动域内包含 a 或 b 的最优补全值之有效上下界。完整接触库用于构图，不意味着把 72h 全图重新优化至最优。记录中的 `full_schedule_*` 是固定 F 加局部选择的可行完整集合值，仍受同一边界限制。

## 核心进展：完整 base9 的严格矛盾环

新要求 quotient：**225 条严格要求、168 个完整九字段类、450 次端点发生项、0 自环、存在长度 2 的有向环**。新旧兼容合并：743 条严格要求、970 类，同样存在环。结论依据严格要求闭环，而不是 alias 数量。

冻结 quotient 返回的主案例为 `CP-AU-r000:q008:d16`。a=`S-P01-S05:GS04:p0001`，b=`S-P01-S05:GS05:p0001`，均为东站群动作。共同边界为 F=1413、P=64、X=10990 个接触，D=16；同一 a/b 在 E/J 均可行且竞争。E→J 只把西站群 gap 从 340 改为 1200，a/b 自身东站群 gap 都保持 1200。

**每项动作各自的九字段在 E 与 J 完全一致；并非 a 与 b 在同一图中的九字段相等。** 下表分数均为精确数值，浮点聚合保留其真实二进制有理数：

| 字段 | φE(a)=φJ(a) | φE(b)=φJ(b) |
|---|---|---|
| weight | 525793139/1000000 | 278192667/500000 |
| duration | 525793139/1000000 | 278192667/500000 |
| degree | 9 | 8 |
| conflict_weight | 2552119897977717/549755813888 | 7978391069079221/2199023255552 |
| max_conflict_weight | 558828533/1000000 | 139794277/250000 |
| compatible_weight | 7025412652536015/274877906944 | 7295764599359549/274877906944 |
| station_gap | 1200 | 1200 |
| satellite_gap | 150 | 150 |
| remaining_count | 64 | 64 |

认证偏好却相反：

- E：`ΔE=Va−Vb=+97.768692 秒`，严格要求 `f(φa)>f(φb)`。
- J：`ΔJ=Va−Vb=−423.700893 秒`，严格要求 `f(φb)>f(φa)`。

因此，单个仅以这九字段为输入的确定性逐动作评分函数，无法同时满足两条严格要求。这是当前信息接口的可证不足；重复修补同一评分函数不能解决该冲突。它没有证明某一种新增特征已经充分，也没有证明必须使用 LLM 才能解决。

本例 A 侧仍是 unknown，故不属于“四侧严格的联合独有反转”。但 E/J 两条严格要求已足够构成 G2 证明；不需要把 A 的 unknown 假定为保持。其交互区间为 `[-1532.911511, -382.059018] 秒`。

同一活动域中另外发现两项“双根完整 base9 保持而严格反转”的配置对：AU-r000:q009:d16 的 E→J、AP-r001:q009:d16 的 W→J。与主例合计三项，分布于两来源组；AU-r000 的两个锚点不能视为独立复现。

**结构定位与未解决事项。** 主例 E→J 在同 P 内新增 41 条边，涉及 33 个端点。在变更前 E 图的诱导 P 中，33 个端点全部属于根的同一 64 节点连通分量；a/b 到最近变边端点均为两跳。固定最短路径分别为 a:653→193→242、b:666→513→463，选择按无权距离和原始节点序号，与算法胜负无关。

按预固定规则只计算了 T=邻居的活动域度数之和、Q=邻居诱导边数。E/J 中 a 均为 T=77、Q=16，b 均为 T=60、Q=13，**这两项没有区分配置状态**。Q 可由现有 typed library 的 `count(induced_edges(neighbors(root)))` 表达；T 虽无直接邻居度聚合算子，也可用现有算子的精确恒等式 `|E(P)|−|E(P\N)|+|E(N)|` 表达。变化位于根一跳之外，说明需要研究更远的补全结构；当前不能声称已找到低成本且充分的表示修复。本轮到此停止特征搜索。

## 数据覆盖解释与下一步边界

动作对分布：west-west=72、east-east=42、west-east=6。仅 6 个跨组动作对不足以评价所有跨资源配对；本轮覆盖以同组动作对为主。完整表示保持且严格反转集中在 cap64：E→J 的东组同组对 2 项、W→J 的西组同组对 1 项。cap16 证据充分但未观察到这类冲突，cap128 有自然表示相等却没有双侧严格证书，不能据其 unknown 推断不存在信息瓶颈。

全部 720 个配置对发生项中，228 个同时保留 a/b 的完整九字段；其中 94 为认证保持、131 为 unknown、3 为严格反转。三项反转跨两个开发来源组出现，为重复证据，仍未构成 TEST 泛化验证。

门槛判断为：G1 有认证配置反转；G2 首次有完整九字段严格矛盾环；G3 原 B&B 未见认证参考头最终收益改善，新 commit 接口显示有限的作用通道。本轮的合理进展是**建立表示修复问题真实存在的数学依据**，而不是宣布旧冻结算法已经有效、LLM 已改善质量或论文已达到录用标准。

下一阶段应先明确能把正确决策转化为调度收益的执行接口，再围绕该真实冲突探索能访问更远残余结构的低成本 typed 表示。LLM 的候选作用是根据认证结构见证组合图操作与规则，并接受一致性、质量和成本的联合筛选；当前没有实验结果可宣称其优于人工设计或其他学习方法。未来的泛化评价必须使用未曝光来源/配置，不能把这批 TRAIN 开发集重新命名为 TEST。

当前交付不自动启动新 P1，不增加 oracle 时间，不再进行特征扫描或物理扫参。卫星 gap150→600 方向已在标签前因四源图完全不变而被数学筛选否决；下一轮明确不再运行该方向。
