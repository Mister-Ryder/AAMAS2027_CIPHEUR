# 两类资源约束同时改变：有界开发实验

本轮依据2026-10-05用户提出的“进一步推进复杂性，比如单次多配置改变”开展，独立于已冻结的P0结果。原始机会库、旧图、旧标签及原Word方案不覆盖修改。

**输入筛选结论：本候选卫星轴不生效，已停止进入标签和求解实验。** 四库均严格满足 `E_S=E_A`、`E_J=E_G`，收益和顶点也一致。因此对任何共同合法边界，条件交互量恒为0，联合独有反转不可能成立。16张图和设计代码保留供审阅，未运行solver、LLM或四侧pilot；未运行的查询不能填成tie或unknown。证明见 [输入同一性证明](analysis/INPUT_SCREEN_tau600_PROOF.md)。

原始输入中首个新增卫星边需超过约5392秒，已接近90分钟。没有恢复/能量等明确场景依据时，不继续将切换间隔抬到这一量级。实际推进方案转为同级 `heterogeneous_ground_v1`：两个地面站群各自拥有独立的资源间隔配置，保持卫星间隔150秒。

## 固定干预

复用四个已完成的STK完整机会库，即r000/r001两个TRAIN开发来源组的AU/AP几何。每库约12,000个完整窗口；不重新传播、不裁分窗口、不重赋权、不增加天线容量或业务模型。

| 配置 | 地面间隔（秒） | 卫星间隔（秒） | 干预角色 |
|---|---:|---:|---|
| A | 340 | 150 | 原配置 |
| G | 1200 | 150 | 只加严地面约束 |
| S | 340 | 600 | 只加严卫星约束 |
| J | 1200 | 600 | 两类约束同时加严 |

所有地面站使用对应地面间隔，所有卫星使用对应卫星间隔。600秒是预声明的开发压力参数，未声称它来自已验证的硬件测量。各配置都是静态调度问题；没有求解过程中的在线配置切换。

## 要回答的问题

1. 联合变化是否改变条件动作偏好？单独变化是否已能解释这种反转？
2. 相同接触、收益及外部边界下，条件偏好差是否存在两个约束因素的非加性交互？
3. 更复杂的真实邻域是否让排序改变可行结果和计算成本？
4. 全部严格要求按实际完整base9连接后，是否出现原表示不能满足的自环或有向循环？

增加边数本身不作为优势证明。新增决策反转也不直接作为表示不足或LLM合成优势。

## 预声明证据与执行预算

每库只用原P0注册查询前10个动作对作锚点，不读旧标签或方法胜负来选例。共同外部调度由J图的固定Degree初始化得到；按新J的邻域扩展到8/16/32个被移除活动，真实活动域上限16/64/128。若动作阻塞种子已超过该档预算，名额保留unavailable；不另找成功例。

每个四配置查询固定同一动作a/b、外部调度F、活动域P和排除域X。a/b须在四侧都可行且竞争。每查询的八个条件动作空间合计先给2秒合法界计算额度，与旧方案四个空间1秒等比例。严格、平局、未知和不可用均保存。

令各配置的条件偏好差为Δ=V(a)−V(b)，交互量为I=ΔJ−ΔG−ΔS+ΔA。区间按合法界传播，不以估计值冒充证书。联合独有反转只在四侧全部严格、A/G/S方向相同且J相反时成立。六种配置配对关系由同一批四侧证书派生，不重复求解。

实际执行分别记录固定2,000节点的B&B和明确命名的pairwise commit诊断接口；Degree、旧冻结控制头及离线认证参考头共享活动域和补完规则。计入全部特征及搜索成本。参考头不是可部署方法；旧冻结头不是本轮新LLM提案。
