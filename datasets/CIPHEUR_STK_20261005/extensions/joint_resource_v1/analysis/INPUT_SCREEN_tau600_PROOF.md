# 150→600秒卫星轴的输入同一性证明

本文件仅解释已完成的建图筛查，不包含新标签、调度优化或模型调用。四个配置是A=(340,150)、G=(1200,150)、S=(340,600)、J=(1200,600)，括号为地面gap、卫星gap秒数。使用同四个STK原机会库、完整窗口和原始端点差收益。

`joint_graph_summary.json` 逐源记录 A→S、G→J 的新增边和删除边均为0；接触、资源和收益保持相同。

这不是“边数看起来相等”的推测：保存的转移统计直接计算了边集合差，确认 **E_S=E_A、E_J=E_G**。当前卫星600秒轴在联合冲突图中完全退化；不能把两个参数数字不同当作两个有效约束干预。

## 不需要oracle的结论

固定任意相同且可行的边界F、域外排除X和同一受限域P。令M_C(a)为配置C下固定a后、同一边界内的最优完成收益。由于顶点、收益及边集合完全相同，两配置之间存在恒等的等权可行解双射：

\[
M_S(a)=M_A(a),\quad M_J(a)=M_G(a).
\]

对b也成立，故其偏好差满足：

\[
\Delta_S=\Delta_A,\quad\Delta_J=\Delta_G.
\]

这针对所有有效a/b和任意共同边界成立，不需要预先求解每个查询。它没有给出这些条件最优值的具体数字。

四格交互因而严格为：

\[
I=\Delta_J-\Delta_G-\Delta_S+\Delta_A=0.
\]

“四侧均严格、A=G=S方向而J相反”的联合独有反转不可能发生，因为A=S且G=J。A→J的任何严格反转只能与A→G的反转相同，无法归因于卫星轴新增的作用。

按A/G/S/J顺序，全部四侧均strict时只可能出现 `++++`、`+-+-`、`-+-+`、`----` 四种方向模式；`+++-` 与 `---+` 两个联合独有模式不可能出现。此处是由图同一性推出的可能性限制，**不是已经观测到的模式频率表**。

## 执行决定与范围

因此停止该600秒端点的四侧标签、B&B和commit实验，避免重复求解同一问题。16张图、建图记录和准备中的quad脚本保留为输入筛查结果。没有把未运行名额填为unknown或tie，也没有生成伪造的标签库存。

base9中显式satellite_gap坐标会改变，但可行集合不变；特征数字变化不能代替决策问题变化，不能据此声称联合适应或信息修复优势。

该证明只覆盖这四个冻结原机会库与当前150/600端点，不证明卫星切换约束在其他端点或场景无效。如后续结构标定另一个端点，必须在读取标签和方法胜负前，根据原始同卫星接触的真实间隔及非冗余新增边暴露量固定参数并重新注册；本文件没有启动该步骤。
