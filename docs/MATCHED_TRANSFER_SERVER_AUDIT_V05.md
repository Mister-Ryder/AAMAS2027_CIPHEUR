## Scientific interpretation

The server replay changes cap coverage, not the underlying completed-policy semantics. For example, C3 witness and relations arms now both complete 96/96 assignments and both average **68.6264232744% U**. Objective feedback averages **68.9909104632% U**, while Degree is **68.2325807046% U**. The local witness disadvantage partly reflected interrupted assignments; its removal does not create a witness advantage. Objective's C3 result is **98.1218322535% of the prior feasible L**, so the small difference from Degree does not surpass that independently verified earlier solution.

On SATLIB, Degree completes 30/30 contexts in each weight view while each authoring arm completes 40/120 repeated assignments. Upper-normalized SATLIB means therefore remain strongly affected by the uncensored cap failures. Neither the local nor server study supports a broad witness-over-label or LLM-superiority claim. Unit/hash variants share 48 public sources; the 24 C3 contexts are 12 source pairs. These are repeated previously observed graphs, not 120 new independent instances. Four authoring banks are descriptive matched units.

Recorded server metadata are Linux/Python 3.11.17, eight workers, 192 visible/affinity CPUs and a cgroup quota of 16 CPU equivalents. Local execution used a different processor/OS/interpreter and 16 workers. A nominal five-process-CPU-second cooperative meter does not make host throughput or feature work equal. Actual timers include AST parsing before the meter, scheduling and overshoot; source reconstruction is separately recorded. The server's total wall duration of approximately 484.67 seconds must not be divided against the local 367.67 seconds as a solver speed ratio without accounting for worker count and host differences. Host costs are recorded measurements, not independently remeasured inference/model latency.

The experimental source verifier reconstructed original C3 conflict edges and checked source predicates. This independent auditor verifies exact graph/source identity, local source CSV bytes and original graph feasibility, rather than implementing a second physical model. Server source CSV metadata match the immutable local CSV SHA. Bounds U are sound clique-cover bounds, not claimed optima; L is an earlier feasible solution and may legitimately be exceeded.
