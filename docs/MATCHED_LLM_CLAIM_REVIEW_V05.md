# Independent scientific claim review of the matched LLM pilot

This is an independent claim audit, separate from manuscript prose, the experiment-results report and the authoritative analysis script. It includes the completed registered TEST review. No response, programme, selection rule or experimental source is changed by this audit.

## Authoring contribution and limits

All twelve cold CLI authoring cells are recorded, with four cells and 48 original candidate slots in each of three arms. Their requested model/provider/reasoning settings match: `gpt-6.1-sol`, `openai`, `ultra`. Retained events do not expose an actual served-model identifier. Each exact last assistant message matches the saved response bytes and all-cell completion hash chain. The 173-check metadata-only receipt audit passed with zero errors. Three recorded packet-read commands failed before process creation; three collaboration waits addressed no receivers. No successful evaluation, oracle query, outside-data tool action or extra authoring agent is recorded in the retained events. Every cell received its frozen packet inline, including those with a failed attempted file read. No cell was excluded or retried on that basis.

The model actually authors typed feature expressions and ranking rules; it is not invoked by the scheduling runner. This establishes genuine offline LLM participation. The three arms all use an LLM, however. Their comparisons can inform the incremental role of evidence in this particular authoring interface; **they do not identify an LLM-versus-non-LLM effect** or prove that the same programme could not be discovered by a conventional grammar search.

Generation compute is visibly unmatched despite equal original-slot/session counts. Reported output-token totals are 41,311 (witness), 25,143 (relations) and 22,075 (objective); mean session wall times are 455.3, 334.8 and 281.2 seconds. Input/cached-input totals are preserved separately. CLI usage is not a count of backend API calls, and requested settings are not observed provider-model metadata. No monetary cost is inferred.

## Incremental explicit-join claim

The selected A and B programmes largely converge to a neighbourhood clique-cover ratio. A0 and B0, and A3 and B3, select the same rule and attain identical TRAIN quality/work. A1 adds a small neighbourhood-packing term to the cover ratio: TRAIN quality is unchanged, while normalized work increases from 6.84 to 9.56. B2 has a small quality/work advantage over A2 under the common selector. These observations provide **no TRAIN support for an incremental explicit-join advantage over the same certified labels**.

A2 declares three additional edge-summary features that its score does not reference. The demanded compiler omits their calculation during ranking. The full declared-interface gate checks all declared features, including unused ones; passing that gate therefore does not prove that deployed scores use every distinction. This does not alter any authoritative slot status or frozen programme, but it prevents interpreting declared expansion alone as active adaptive reasoning.

The authoritative duplicate filter hashes normalized typed feature trees plus the exact rule string, ignoring name/rationale. Its precise scope is removal of identical serialized feature–rule programmes, rather than complete detection of semantically equivalent policies. The independent audit found no within-cell whitespace-only parsed-rule-AST duplicate variants in the retained static-valid slots.

## Defensible interim narrative

- Genuine contribution: an inspectable offline model authoring stage proposes deployable typed feature–rule programmes under a shared interface; every assigned output and inference failure is preserved.
- TRAIN observation: adding certified relation labels increases full-frame interface eligibility and mean scalar agreement relative to objective-only prompting in this four-block pilot.
- Unestablished advantage: explicit equality joins add no observed TRAIN quality benefit over the same certified labels. Held-out comparisons remain necessary before a deployment-quality conclusion.
- Separate scientific evidence: independently verified public strict aliases prove finite base-interface impossibility. The current frozen primary fails both full-graph strict preferences, demonstrating the gap between diagnosing a missing distinction and fitting a successful rule.
- Generalization limits: four authoring blocks, one shared evidence packet and unmatched generation tokens/latency do not establish model-population superiority, physical natural-obstruction incidence or a necessary LLM advantage over search.

Keep cost receipts, startup/tool failures, hash chains, source conversions, detailed slot inventories and this audit in Markdown/JSON reports. A concise main-paper discussion should state the evidence-arm question, the separate interface/rule obligations, the four-block limit and the actual positive/null/negative held-out contrasts. It should not become an engineering delivery log.
