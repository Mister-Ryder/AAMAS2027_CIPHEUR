# V05 AI participation and authoring provenance

The LLM is an offline typed feature–rule proposal generator. It does not certify conditional optima or enforce deployment feasibility. Human authors remain responsible for mathematical claims, citations, measurements and the manuscript. No fine-tuning or DeepSeek harness was used.

The independent study has four authoring blocks, three prompt arms and twelve original slots per cell. A receives certified relations and explicit equality joins; B receives relations without joins; C receives objective feedback without labels. All graphs, typed grammar, proposal limits, full-interface gate and TRAIN selector are common. The entire 144-slot bank was frozen before assessment; no replacement, output repair, TEST selection or fallback winner was introduced.

All twelve fresh native Codex CLI sessions requested `gpt-6.1-sol`, OpenAI provider and `ultra` reasoning under the same local configuration. Retained events do not identify the served backend model. These are twelve CLI sessions, not a known number of backend API requests. Token usage and wall latency are recorded: output totals are 41,311 / 25,143 / 22,075 for A/B/C. Slots and settings are matched; tokens and compute are not. Input totals include repeated/cached context, and cached input is not counted again as extra input.

The original collaboration transport reached its thread limit. A transport amendment, made before outcome assessment, excluded one pilot and moved every arm to cold CLI authoring. Its original response remains preserved under `experiments/discovery/v05/authoring_pilots/`. Scientific packets and limits were not changed. A metadata-only audit found no successful outside-data or nested-agent access; unsuccessful packet-read/tool attempts are recorded. Raw authoring outputs, event hashes and receipts remain unchanged. This is bounded evidence of the executed transport, not proof about unobserved model training or backend internals.

The frozen operation documentation incorrectly describes `div` as a near-zero guard, while the executed feature operation rejects exact zero and otherwise divides normally. All arms share this frozen wording; it was not repaired after authoring. Observed TRAIN failures were CPU budget failures, not division exceptions. Serialized feature trees plus literal rule strings define duplicate removal; this is not complete semantic-equivalence detection. The independent auditor found no whitespace-equivalent AST duplicates in the realised bank.

The selected programs were frozen on 66 TRAIN contexts, then 216 new TEST contexts were generated from registered, disjoint namespaces. All 2,808 TEST assignments completed without online model/oracle calls. Labels improve descriptive four-block mean quality by 0.657 points over objective feedback; explicit joins add only 0.014 points over labels. The pilot supplies no LLM-versus-non-LLM causal arm and no model-population confidence claim.

The later 1,560-assignment public/C3 extension reuses the twelve original frozen winners plus Degree and previously observed inputs. It was executed locally, with 1,007 completed schedules and 553 retained CPU-cap failures; no new authoring, winner selection or online model calls were introduced. It shows no general witness-guidance transfer advantage. Its U/L denominator definitions, local runtime and cooperative cap scope are separate from the original pilot and older native-server study. User-requested server replay and checking of the original 2,808 TEST platform are pending; this disclosure does not certify future server completion.

The latest user request rejects treating this candidate as the final algorithm and starts V06 structural local-repair development. That work is a new research design, not a post hoc improvement attributed to the old unchanged AST or the twelve cold authoring sessions. Any later model proposal, local-search kernel, TRAIN iteration and server experiment needs its own actual provenance. No new model calls or achieved V06 quality gains are asserted here, and release preparation is paused while the research goal remains incomplete.
