## Question and separate populations

The natural temporal TRAIN strict bank has an acyclic nine-field base quotient, while previous contradictions come from constructed diagnostics. Public integer-weight graphs may contain genuine exact base-feature collisions with different conditional completion values. We test that possibility without assuming a positive result.

Track 1 contains **13 full unit-weight DIMACS conflict graphs of at most 256 vertices**: C125.9, C250.9, MANN_a9, brock200_1…4, hamming6-2, hamming8-4, johnson8-2-4, johnson16-2-4, keller4 and san200_0.7_1. These are the exact existing public clique-complement MWIS inputs; no SATLIB full graph meets the vertex cap. A full-graph strict alias can support an information obstruction on that public algorithmic instance, not a naturally occurring satellite scheduling obstruction or a resource-intervention reversal.

Track 2 contains **48 source-derived induced graphs**, one deterministic subset of at most 32 vertices from every unit-weight source in the existing 18 DIMACS + 30 SATLIB public inventory. Vertices are the first 32 by SHA256 of the registered salt, source ID and original vertex ID. Contacts/weights and all induced edges are preserved. This changes the optimization instance and is explicitly not a full benchmark or a sample of physical scheduling. The original 28-vertex graph yields the same graph in both tracks; other tracks also share sources. Tracks are never pooled or treated as 61 independent source samples.

The original input archive is `experiments/runs/v04/public_data_v04_002.tar.gz`, SHA256 `e13f8d925fc59c900f772f0c7a9dace376cfd2c188f836b82bf20b49419970d3`. ## Query acquisition before outcomes

Only the initial empty fixed/excluded boundary is used. All nine base features are evaluated exactly as supplied by the existing runtime. Existing competing edges are sorted lexically; the first at most eight edges whose endpoint base vectors are exactly equal are retained. There is no approximate/rounded identity test, graph-structure feature ranking, oracle-result filtering or replacement after an unknown result.

Preparation freezes all graph inputs, original source identities, exact alias endpoint vectors, complete query ordering, eligible-pair counts and quota shortfalls before calling any oracle. The resulting fixed plan has **61 graph states / 324 queries**, below the registered ceiling of 488; all 164 quota shortfalls remain visible. Input-only inspection and computing base features is not certificate acquisition.

## Registered bound and wall budgets

Each graph state uses the unchanged `CancelledCompletionOracle` with 2,048 search nodes per unmatched component, searchable component size at most 256, total 16,384 expanded nodes, and at most 32 component calls. All queries in a graph share its cache/budget. Exact component identity cancels common unknown continuation terms. Budget exhaustion retains sound intervals and unknown status rather than forcing a preference.

Four workers execute on Linux with a 120-second per-state wall alarm. Completed comparisons preceding an interruption remain saved; the interrupted and every remaining assigned query is explicitly unresolved. The completed search-node receipt ceiling is **999,424** across all 61 states. Interrupted in-flight work is marked separately because the unchanged oracle records nodes at completed-call boundaries; the completed-node counter is not a complete measurement of interrupted CPU work. The worst-case wall ceiling is about 30.5 minutes for 61×120 seconds with four workers, plus process/output overhead; this is a bound, not an expected runtime promise.

Every completed comparison saves rational intervals, common/unmatched component partitions, feasible lower witnesses, strict/tie/unknown status and oracle costs. Any strict requirement over exactly equal base inputs is a self-loop obstruction for a deterministic pointwise base scorer. This supports a statement about that specific finite evidence, not every graph or global scheduling loss.

The frozen V04 programme is evaluated only on those same endpoints to record whether its declared features distinguish them and whether its scalar scores agree with a strict relation. A pairwise score agreement is not a claim that the full kernel chooses that action, that all other competitors are correctly ranked, or that the programme obtains a better complete schedule. Zero model calls and no programme selection are recorded.

## Verification boundary

Exact arithmetic, component cancellation, original graph feasibility and lower witnesses are inspectable. As in the earlier oracle, complete large-component branch-and-bound frontier proofs are not exported by the unchanged implementation. A later independent small-component exact check can strengthen the induced-track proof evidence, retaining any audit exhaustion as an explicit verification gap. A saved upper number must not be called independently proved merely because its code hash matches.

Even a positive public alias result does not identify an LLM-guidance benefit. It supplies additional information-obstruction evidence. The matched cold-authoring pilot remains blind to this study and uses its original frozen packets. Natural physical scheduling necessity and reversal/preservation under a physical resource intervention remain separate questions.
