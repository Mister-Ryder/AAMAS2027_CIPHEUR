## Genuine LLM pilot curves once results exist

This advice uses only `docs/MATCHED_LLM_PROTOCOL_V05.md` and the runner's declared output schema, not any authoring responses or outcomes. The pilot assigns four paired cold-authoring blocks, three evidence arms and twelve authoritative output slots per cell. Missing, invalid and exact duplicate AST slots remain failed attempts. The plotted x-axis should therefore be the original slot prefix `k=1,…,12`, with no deletion or sorting by eventual quality.

Two distinct diagnostics directly answer what the evidence-guided LLM contributes:

1. **Representation-yield curve:** the cumulative number or fraction of eligible full-interface DAG candidates after the first k assigned slots. All failed slots stay in the denominator. Use the same gate for all arms, preserve individual block traces, and separate the full bank from any natural-only diagnosis. A DAG pass is not scalar preference agreement.
2. **TRAIN best-eligible utility curve:** for each block and evidence arm, `U_b,arm(k)=max J(p)` over eligible proposals among original slots ≤k. Use the registered TRAIN utility and exact early-slot tie rule. Plot a step line only once an eligible proposal exists. A no-eligible prefix is missing/unavailable, not a utility of zero, an invented lower bound or an implicit fallback. The fixed feasible reference is not an optimum, so utility/quality ratios may exceed one and should not be capped at one.

Four block traces, or four small multiples, are safer than a falsely precise pooled model curve. If a compact aggregate is used, show the number of eligible blocks at every prefix and retain all block traces; avoid a mean conditioned silently on successful authoring. Pointwise min–max spread of four blocks must be labeled spread, not a 95% confidence interval. Source-case bootstrap intervals alone cannot measure model-generation uncertainty.

The primary guidance contrasts are witness-minus-relations and relations-minus-objective within each block. A final TEST comparison uses the already TRAIN-frozen winner for each complete twelve-slot cell; do not choose a prefix or a best block after observing TEST. Any test-source uncertainty must retain paired graph interventions, shared regime seeds and four authoring blocks as separate uncertainty sources. Hundreds of test graphs do not create hundreds of independent LLM generations. Four paired authoring blocks cannot produce a fine-resolution population claim; even four positive signs have coarse exact two-sided sign/randomization resolution.

Keep proposal-efficiency diagnostics separate from measured generation CPU/wall/tokens. Twelve output slots may be created in one LLM session, so the x-axis is assigned programme attempts, not twelve model calls, dollars or tokens. Report actual CLI session/model/settings and available usage in the provenance report. Do not borrow the earlier assistant transport's zero-external-API description for the new CLI transport.

The final interpretation should follow the data: improved yield with unchanged/decreased utility is a representation-search finding, not a schedule-quality advantage; improved TRAIN utility without frozen fresh confirmation is not generalization; a negative pilot must remain visible. The existing V04 control/native-solver limitations remain separate even if the pilot is positive.
