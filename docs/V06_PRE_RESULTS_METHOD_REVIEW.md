# Independent V06 method review before R2 results

Review date: 2026-10-04. Scope: the six V06 draft fragments, the declared
R2 analysis and selection protocols, prior formal reviews, and the revised
TRAIN concept illustration. No R2 response, assessment, receipt or TEST
outcome was read. This is a review of scientific framing and design, not a
prediction of effectiveness or acceptance. Only this review file is authored
by the reviewer.

## Scientific contribution and current support

The defensible central contribution is **using sound conditional optimization
preferences to expose an exact information obstruction in a heuristic's
current inputs, then supplying its concrete equality joins to joint typed
feature/rule synthesis**. The complete finite quotient is essential: a rule
can fail without an input obstruction, and two individually non-aliased
preferences can still become contradictory through equality joins.

This is more focused than claiming feature invention, LLM-guided heuristic
generation, counterexample-guided refinement, or stronger local search as new.
Theorem 1 is a useful exact characterization, but its proof is the standard
finite strict-order/topological-ranking argument. Theorem 2 is a scoped
cut-generation optimality argument for a fixed finite catalogue. Neither
alone establishes deep new optimization theory. Scientific depth must come
from how the certified target changes learning, how much authoring effort it
saves, and whether useful distinctions survive deployment cost and distribution
change. Classical repair strengthens the test platform; its improvement is
not evidence for that learning contribution.

Known R1 facts already constrain the story: its original release barrier
failed, all assessed candidate TRAIN qualities tied, and the shared repair
kernel made very few improvements. Those are informative negative findings.
R2 tests bounded repair of a selected ineligible seed, rather than independent
cold authoring. A positive R2 information result would therefore support
conditional representation repair; it would not reverse R1 or establish
general LLM advantage.

## Formal assumptions that must remain explicit

For Theorem 1, equality must use the **complete represented input at every
observed occurrence**, the scalar must be deterministic and pointwise, and
every observable scorer input must be included. A hidden identifier, history,
configuration field or separate evidence channel invalidates an inference
that these inputs force contradictory scores. Finite DAG sufficiency is for
an unrestricted scalar; finite expression bounds, score ranges and the
particular DSL can prevent realizing it. Complete cross-state quotient
checking is necessary even when every individual state's quotient is a DAG.

For Theorem 2, fix the evidence, catalogue, feature-value table, positive
standalone costs and capacity. Each master must be solved globally, and its
trial subset replaces previous additions relative to the same base. A
termination claim requires unrestricted finite subset search; a budget stop
is unresolved. Dynamic catalogue expansion requires evaluating new columns
against retained cuts. Generic-table set-cover hardness does not establish
hardness for this bounded graph-operation DSL. The final guarantee is only
minimum additive representation cost within that catalogue and capacity;
neither scalar fit nor shared-DAG runtime follows.

The conditional bounds are sound under the stated nonnegative rewards,
verified feasible packings, valid clique covers and outward-safe arithmetic.
Component cancellation is valid for identical residual induced components
within the same graph; matching names across changed configurations is
insufficient. The budget of the searched subset does not bound all clique,
arithmetic and preparation work. Preserve abstention and the full attempted
query denominator. The counts of strict equal-vector cases describe the
selected finite query inventory, not the incidence of aliases among natural
satellite scheduling decisions.

## Missing predeclared experiments with high information value

These additions should be registered as separate studies before their
outcomes are examined. They should not alter the ongoing R2 cohort, selection,
gate or release barrier.

1. **Restricted-patch ordering assay.** Freeze an outcome-independent bank of
   patches produced by the common TRAIN kernel, with identical destroy set,
   outside commitments, patch vertices, incumbent and search cap for every
   priority program. Replay Degree, fixed structural controls and frozen
   synthesized priorities on these immutable patches. Record pivot/order
   disagreements, best local incumbent, expanded nodes and feature cost;
   obtain restricted optimum/bounds independently where tractable. Keep all
   patches, including ties and no-gain cases. This directly tests whether
   full-graph learned distinctions help the actual local task without assuming
   that full-graph conditional labels certify patch preferences. It is the
   strongest bridge currently missing between representation fit and useful
   search behavior.

2. **A genuine iterative AHD comparator.** ReEvo is a practical first choice:
   it couples evolutionary generation with language-based reflection, rather
   than taking eight objective-conditioned proposals from one fixed seed.
   Its comparison must include the real feedback/update loop, common typed
   DSL and kernel when testing authoring information, TRAIN-only selection,
   identical assessed-slot budgets, and measured calls/tokens/elapsed cost.
   A restricted port must be named "ReEvo-style typed adaptation", with its
   changes disclosed; it is not an unmodified reproduction. A separate
   original-program track is needed for broad end-to-end AHD superiority.
   Existing W/R/O comparisons remain useful controlled ablations but cannot
   stand in for this baseline. [ReEvo, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/4ced59d480e07d290b6f29fc8798f195-Abstract-Conference.html).

3. **TRAIN witness robustness under prescribed renamings.** The displayed
   greedy-packing distinction depends on deterministic identifier tie-breaking.
   Predeclare several renamings of the original TRAIN cycle and report whether
   its join separation survives. Existing withheld-state renaming tests should
   remain unchanged. This separates a stable structural distinction from one
   produced by a particular greedy tie order; neither outcome changes the
   validity of the original exact finite obstruction.

4. **Catalogue audit, only if the theorem stays central.** On a frozen TRAIN
   catalogue, compare exact cut generation with exhaustive enumeration at the
   same small capacity and with a local one-cycle repair lacking full quotient
   rechecking. Report cost, remaining cycles and computation, including
   unresolved/infeasible cases. Without such use, the catalogue theorem is
   better placed in the appendix than presented as a major implemented
   contribution.

The scheduled performance study should report incremental gain over each
pipeline's charged initializer and compare against **full-budget** native
CHILS, not only the half-budget warm seed. Retain actual wall/CPU time,
overshoot and feasible coverage. Equal nominal targets are not equal hard
end-to-end deadlines. Evidence from alias-enriched unit-weight 32-vertex
states and evidence from larger genuinely weighted inputs answer different
questions and need separate tables. Raw objectives must not be pooled across
families. Four transport-conditional authoring blocks support descriptive
contrasts, not confident population-level model efficacy.

## Closest published synthesis work

The current related-work paragraph correctly concedes that open-ended code
can already invent structural computations. It should additionally cover:

- **A₂DEPT, ICML 2026:** complete solver-program evolution, hierarchical edits,
  function-level maintenance and dependency repair; its evaluated domains
  include MIS. The full method changes solver architecture rather than
  diagnosing whether a fixed scorer input interface can express certified
  preferences. This is an important comparator for the claim that richer
  programs overcome limitations of fixed heuristic templates.
  [Official paper](https://proceedings.mlr.press/v306/chen26hb.html).
- **PathWise, ICML 2026:** a derivation/entailment graph stores heuristic-search
  history, while policy/world-model critics route performance-based reflections.
  Its graph is search memory, unlike our quotient of identical decision inputs.
  It is especially close to generic claims about state-aware, targeted
  heuristic refinement; the distinguishing claim must concern sound
  conditional inequalities and exact equality-join obstructions.
  [Official paper](https://proceedings.mlr.press/v306/gungordu26a.html).

This comparison is based on the published method passages, not an assertion
that we reproduced either system or exhaustively proved absence of every
related component. EoH's description/code evolution and LLaMEA's fitness/error
feedback further prevent treating joint program editing or executable feedback
as standalone novelty. [EoH, ICML 2024](https://proceedings.mlr.press/v235/liu24bs.html),
[LLaMEA author implementation and published citation](https://github.com/XAI-liacs/LLaMEA).
Absorbing strong classical components is compatible with the adopted abstract;
absorbing established generative search should be credited and experimentally
separated from the certified information diagnosis.

## Concept illustration: independent semantic check

Read-only replay from the original TRAIN graph independently gives full
conditional values **34=15, 5=14, 7=15, 35=14**, and `exclude_lb` values
**13,13,12,13** in that order. Original vectors equate 34 with 35 and 5 with 7,
so requirements 34→5 and 7→35 induce a two-class directed cycle without a
self-loop. Replacing `residual_pack` with `exclude_lb` preserves six additions
and fifteen total coordinates. For these four occurrences only, the refined
classes produce exactly **7→{34,35}→5**, a three-class DAG with two arcs.

The updated φ′ caption is scientifically appropriate. It should also make
clear that the displayed feature value is an input, not the score, and that
the LLM-authored feature comes from an existing R1 proposal rather than a new
successful witness-guided response. The figure demonstrates a genuine
TRAIN obstruction and an executable local distinction; it establishes no
full-inventory consistency, fitted complete rule, R2 yield or schedule gain.
An LLM icon alone must not imply that the shown replacement was produced by
the ongoing R2 run.

## Body-space allocation and editorial focus

The current fragments contain approximately 3,535 prose words before an
experimental section, captions and formula space; the method alone has about
1,511 prose words and eight displayed equations. These counts are a planning
aid, not verified typeset page counts. A reasonable eight-body-page allocation
is: introduction/concept figure 1.15, related work 0.55, problem 0.60, method
2.05, experimental protocol/results 3.20, and discussion/conclusion 0.45;
reserve the ninth page for references if the submission format permits it.

Keep component cancellation, the actual global quotient cycle, the distinction
between demanded interface and numerical rule fit, and the controlled learning
contrast prominent. Describe the classical kernel in roughly 180–220 words
with one patch equation and citations. Move the optional master's detailed
proof/complexity, long cap lists and operational provenance to the appendix.
Use the actual cycle and one compact authoring/deployment flow as the primary
concept figures; an engineered reversal example needs a clear diagnostic label
and need not consume another large figure.

The current main manuscript still uses older V05 input fragments and figures.
Those should not be treated as integrated V06 validation: in particular,
irreversible-greedy execution graphics must be replaced and the phrase
"no oracle" qualified as no online LLM or full-residual certification oracle,
because bounded classical search remains active. The results section should
lead with what the explicit witness changed in representation/fit and cost,
then assess deployment quality separately. It should not lead with gains that
all arms receive from the stronger shared search module.
