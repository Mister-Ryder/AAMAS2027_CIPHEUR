# AI assistance and author responsibility

This file is an accompanying disclosure record, not a manuscript author list.
Human authors remain responsible for the scientific claims, reference accuracy,
data provenance and final submission.

Codex assisted with implementation, experiment planning, manuscript drafting,
editorial integration and figure preparation. Separate agents drafted the
introduction, related work, problem formulation, method, experimental sections,
discussion and conclusion; the root agent integrated their contributions.
Experimental LLM proposals are a distinct part of the method, with their
original prompts, responses, requested settings and native call receipts
retained in the public evidence. Offline authoring precedes programme freezing.
The deployed programmes make no online model calls. The optional local
DeepSeek harness was not used.

R2 comprises fifteen authentic authoring requests producing 120 proposal
positions. The EoH-DSL comparison comprises 32 authentic sequential author
calls and four seed fitness observations. Requested model settings are recorded
where available; served model identity is not reported by these receipts and
must not be inferred from a configured name. Proposal positions, authoring
blocks and the four identical retained EoH seed outputs are not independent
samples of different models.

AI image generation assisted the illustrative scheduling scene and structural
witness illustration. They depict labelled constructed/recorded examples;
captions delimit their scope. Numerical experimental panels are produced from
frozen analysis records using standard scientific plotting. They are not
image-generated measurements. The algorithm diagram also has an editable
draw.io source. Prompts and figure provenance are retained with the assets.

Deterministic code checks feature syntax, finite numerical values, complete
quotient obstructions, preference fit, feasibility and frozen selection.
Independent result checks reconstruct scientific quantities from saved bytes;
they do not substitute for author responsibility. Negative and null outcomes
remain in the reports. No claim of guaranteed acceptance, universal LLM
superiority or unmeasured scheduling improvement is supported.
