# Matched cold-authoring pilot V05

Registered on 2026-10-03 before any new candidate assessment. Scientific scope: distinguish explicit witness guidance from certified-label feedback under the same LLM authoring interface. This is a new pilot following the known V04 limitations, not a reanalysis presented as a fresh V04 result.

## Fixed comparison

Four paired cold-authoring blocks, three arms and twelve authoritative output slots per cell give 12 authoring sessions / 144 slots. Every arm receives the identical typed graph-operation library, nine base features, limits, 12 deterministically selected natural TRAIN context snapshots plus 2 small prior diagnostic graphs, and the same classical degree-rule schedule feedback. The 14 distinct masked graphs contain no selected LLM programme or prior held-out result.

| Arm | Common examples and objective feedback | Saved certified relations | Explicit quotient equality joins |
|---|---|---|---|
| `witness` | Yes | 17 packet relations | Yes, 1 concrete self-loop join |
| `relations` | Yes | The same 17 | No |
| `objective` | Yes | No | No |

Full authoring packets remain approximately 80 KB each in compact JSON. The example selector uses family, size and graph digest before the new outcomes. Every masked label's actions remain feasible under its mapped boundary; the mapped degree reference's reward and feasibility are checked. No selection of packet snapshots by V04 programme quality occurs.

The complete runner-only TRAIN frame remains 66 graph contexts, 824 saved strict requirements and 668 endpoint occurrences. It is forbidden to cold authors. The actual-only 788-requirement base quotient is acyclic; prior diagnostic motifs supply all 32 self-loops. Diagnostic repairs must never be described as naturally discovered obstructions.

## Frozen files

`experiments/discovery/v05/protocol.json` and `freeze_receipt.json` pin all packets, prompts and `training_evidence.json`. Packet/prompt files are `packets/block_N_ARM.json` and `packets/block_N_ARM.prompt.md`, where N=0…3 and ARM is one of the three table entries. Original files must remain unchanged.

Cold authors may read only their own packet and prompt. They may not read old programmes/banks, manuscript/results, other responses or any test data; they may not evaluate schedules or query the certificate oracle. The authoritative response has exactly this shape:

```json
{
  "version": "matched_cold_bank_v05",
  "block": 0,
  "arm": "witness",
  "candidates": [
    {"name": "short_name", "features": [], "rule": "weight", "rationale": "brief hypothesis"}

```

The schema example shows one object for readability; the actual response contains exactly twelve candidate slots. Each candidate has exactly `name`, `features`, `rule`, `rationale`. Missing, invalid or exact duplicate deployment AST slots are retained as failed attempts, without repair or replacement. Names and rationale text do not make an otherwise identical features/rule AST a distinct proposal. Duplicates across independently authored cells remain valid separate generation observations.

## Equal TRAIN gate and selector

Every arm passes the same full declared-interface acyclicity check on all 824 strict TRAIN requirements. Whole declared feature vectors are checked, even for fields unused by the score. Scalar strict agreement is an additional diagnostic, not redefined as interface validity. Feature-runtime failures fail the gate.

All static-valid slots execute complete TRAIN schedules through the unchanged demanded compiler under a five-process-CPU-second cooperative cap. Timeout/invalid score retains null schedule, trace, value and completed-work fields; no fallback is used. All invalid/missing/duplicate slots remain in the assigned denominator. Measured feature work, CPU and wall time are saved.

Utility is the equal-family mean of reward divided by the frozen V04 TRAIN bank's strongest saved completed feasible reference, minus `0.002*(equal-family relative feature work − 1)`. Work is normalized by frozen Degree work in that same context. The common reward reference is feasible, **not an optimum**; new ratios may exceed one. Failure quality is zero and relative work 100. All arms receive this same selector; highest utility wins, and an exact tie selects the earlier slot. There is no reached-regret tie-break in this prompt isolation study. An arm with no eligible slot retains a recorded no-program outcome and no fallback.

Candidate scheduling order is rotated by graph digest before outcomes, uniformly over the fixed bank. The 12 selected ASTs, all authoring receipts, complete slot bank, TRAIN assessments, full/natural-only quotient diagnoses, protocol/source hashes and unavailable-arm statuses are frozen before new TEST generation. Immutable V04 ASTs/results remain intact.

## Fresh confirmation

The new temporal TEST namespace is 180,000,000; dense/long uses the generator's additional 100,000,000 offset. Both profiles cross 3 resource regimes, sizes 64/128/256, 6 source pairs per cell and 2 intervention sides: **108 pairs / 216 graph contexts**. Three pairs per cell would be only 108 contexts; the registered six fixes that arithmetic before authoring.

Fresh generation occurs only after the TRAIN freeze and never consults programme performance. It compares all released prior tar-archive `data.json` input members' seeds, graph digests and contact fingerprints, reading no prior test outcome member. Any conflict rejects generation without searching for an easier replacement. This inventory covers released inputs; it cannot prove that an unknown private exposure never happened. Common random seeds across regimes and both intervention sides remain one source/seed cluster.

This extension contains **no new physical C3 or public-graph generalization claim**. Existing V04 physical/public comparisons remain visible separately. Evaluation runs all twelve frozen cell selections plus Degree, retaining a failed row for no-eligible cells. A separately timed zero-search clique-envelope reference is an offline evaluation tool and is never called by the deployed ranker. No new LLM or programme selection occurs in inference.

## Analysis contract

The primary contrasts are witness-minus-relations and relations-minus-objective under the shared selector. Report the four paired authoring blocks individually as well as their descriptive average, test-source strata, reward/completion/cost, invalid/duplicate output counts and full/natural-only gate-pass rates. Programmes/relations/test contexts do not become independent authoring replicates.

A TRAIN proposal-efficiency curve may plot cumulative best eligible utility and gate-pass yield against the authoritative slot prefix. It uses original slot order, counts failed slots and is explicitly a TRAIN finite-bank diagnostic. A post-TEST prefix winner or a cherry-picked best authoring block is prohibited.

Four authoring blocks form a bounded pilot. They cannot support a precise model-population advantage claim; exact paired tests have coarse resolution and test-source bootstraps must not erase generation uncertainty. Session counts/settings are matched; token/latency matching is not assumed. All positive and negative results and unknowns are retained. A future redesign requires a new registered study and new test identities.
