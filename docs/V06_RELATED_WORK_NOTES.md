## Central distinction and claim boundaries

The draft's distinction is **certified failure of an input interface to express conditional decision preferences, followed by targeted representation--rule refinement**. It does not claim that earlier LLM algorithm generators cannot invent features or inspect structure. It does not claim that LLM generation, counterexample-guided refinement, relational specifications, graph representation learning, local exchanges or branch-and-bound are individually new.

## New verified formal reference

**Ciaran McCreesh, Patrick Prosser, Kyle Simpson and James Trimble. 2017. On Maximum Weight Clique Algorithms, and How They Are Evaluated.** In *Principles and Practice of Constraint Programming (CP 2017)*, J. Christopher Beck (ed.), LNCS 10416, Springer, Cham, pp.206–225. DOI [10.1007/978-3-319-66158-2_14](https://link.springer.com/chapter/10.1007/978-3-319-66158-2_14).

The [publisher chapter](https://link.springer.com/chapter/10.1007/978-3-319-66158-2_14) verifies the exact title, four-author order, year, pages, LNCS volume, editor, publisher and DOI. The [official CP 2017 accepted-paper list](https://cp2017.a4cp.org/accepted_papers.html) independently lists the same authors and title. The publisher displays **Kyle Simpson**, so the proposed entry follows that name rather than introducing an unverified middle initial. First online publication is 23 August 2017; the formal proceedings year is 2017.

Its abstract specifically identifies bias from the commonly used vertex-number-modulo-200 weight assignment: it can favor weight-based rather than degree-based heuristics, and weight distributions influence inference-rule cost-effectiveness. The paper broadens benchmarks using application-derived families, including winner determination. The related-work paragraph paraphrases this point; it does not copy abstract wording or infer measured effects for our implementation.

The [author-maintained benchmark repository](https://github.com/jamestrimble/max-weight-clique-instances) identifies itself as the companion dataset for this formal paper. Its README lists DIMACS, REF, UAI, WDP, error-correcting codes, graph colouring and kidney exchange. It distinguishes **UAI as maximum-weight independent-set instances contributed by Hong Xu**, while the other families are supplied as maximum-weight clique instances. Consequently, UAI must not be complemented merely because the repository name says “clique”; clique-based WDP requires the explicitly declared complement mapping when used for MWIS. DIMACS-format vertex weights also require exact numeric parsing. The CP paper's abstract alone does not establish the later repository's complete UAI inventory or its current raw numeric compatibility; cite and pin the author repository in the data protocol.

`mccreesh2017evaluation` is a single proposed addition. It has no duplicate title/DOI/key in the existing two bibliography databases and is a formally published CP paper, not a preprint. No new arXiv entry is introduced.
