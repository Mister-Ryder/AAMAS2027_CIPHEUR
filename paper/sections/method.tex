\section{Certified Representation--Rule Refinement}
\label{sec:method}

Our offline synthesis loop separates three failures: an uninformative
representation, an incorrect rule over an adequate representation, and a
ranking improvement that does not improve the executed schedule. It uses
certified residual-state comparisons to refine the first two, and complete
schedule evaluation to assess the third. The resulting feature--rule program
is frozen before evaluation on unseen scheduling problems.

\subsection{Scheduling States and Aligned Interventions}
\label{sec:method:model}
An intervention changes one admissible resource parameter while preserving
contacts, rewards, time windows, and boundary semantics. Configuration is
static within each run. We acquire comparisons at incumbent rollout states:
replay the same $B$ in both configurations, retain an action $a$ that is
the actual next kernel choice on at least one side, and select a common
feasible conflicting challenger $b$. Both must remain individually feasible
and adjacent on both sides. Invalid replays are discarded. Uncertain scores,
structural changes, and program disagreement prioritize queries; they do
not establish preferences.

\subsection{Full-Residual Reversal and Preservation Certificates}
\label{sec:method:certificates}
For the conditional completion value in Equation~\ref{eq:conditional-value}, The scope includes the full residual graph. A budgeted oracle supplies
$L_\theta(d\mid B)\leq V_\theta(d\mid B)\leq U_\theta(d\mid B)$.
Each lower bound has a checked complete feasible schedule containing the
forced action and commitments. Thus all four conditional spaces have
explicit feasibility witnesses.

For scalable certification, let $A=R_\theta(F\cup\{d\},X)$, and search
an interior region $H\subseteq A$. Let $U_H$ bound its induced MWIS
value. Partition $A\setminus H$ into verified disjoint cliques $C_j$.
Then a full-residual envelope is
\begin{equation}
 U_\theta(d\mid B)=w(F\cup\{d\})+U_H+
                 \sum_j\max_{v\in C_j}w_v.
 \label{eq:clique-envelope}
\end{equation}
An independent set contains at most one vertex from each clique; relaxing
cross-region conflicts only enlarges the completion space. Singleton cliques
recover the outside-weight bound. Clique envelopes also bound unexpanded
branch-and-bound states. An interior incumbent is greedily completed and
checked globally to obtain $L$. Progressive region expansion retains the
best valid lower and upper bounds. Exact arithmetic for saved weights and
outward-rounded exported endpoints preserve the inequalities when search
stops early.

For objective tolerance $\epsilon\geq0$, a reversal is certified by
\begin{equation}
 \begin{split}
 L_{\theta_0}(a\mid B)&>U_{\theta_0}(b\mid B)+\epsilon,\\
 L_{\theta_1}(b\mid B)&>U_{\theta_1}(a\mid B)+\epsilon.
 \end{split}
 \label{eq:reversal-certificate}
\end{equation}
Sound intervals imply the corresponding strict inequalities between
conditional optima. The same strict preference on both sides certifies
\emph{preservation}. Overlapping intervals, exact ties, and exhausted budgets
remain unknown. Preservation is therefore positive evidence for a stable
ordering, rather than the absence of a reversal.

Each side contributes a requirement $r=(x^+,x^-)$, where
$x=(G_\theta,R_\theta(B),v)$ is a decision occurrence:
\begin{equation}
 h(\phi(x^+))>h(\phi(x^-)).
 \label{eq:strict-requirement}
\end{equation}
An implementation score margin is distinct from $\epsilon$. These
requirements compare optimal completions with explicit commitments; they
do not certify a heuristic completion or greedy global optimality. To
detect avoidance of the comparison, we record whether a candidate reaches
the saved boundary and, when started there, chooses outside $\{a,b\}$.
Such an escape can be reasonable, but pair consistency then provides no
direct evidence about the next executed choice.

\subsection{From Exact Contradictions to Minimum Feature Repair}
\label{sec:method:repair}
Let $\mathcal D$ contain the accumulated requirements and $\mathcal Z$
their occurrences. Define $x\sim_\phi y$ exactly when
$\phi(x)=\phi(y)$. The quotient graph $Q_\phi$ has equivalence classes
as vertices and an arc $[x^+]\rightarrow[x^-]$ for every requirement,
including self-loops. All scorer-observable semantic inputs belong to
$\phi$; contact identifiers and saved labels are excluded.

\paragraph{Proposition 1 (finite representability).}
An unrestricted deterministic pointwise scalar function satisfies all
observed strict requirements if and only if $Q_\phi$ is acyclic.
\emph{Proof.} A cycle requires a strict decrease back to its starting score.
Conversely, longest outgoing-path lengths on a finite DAG supply a
satisfying score, scalable to any fixed positive margin.\hfill$\square$

Acyclicity does not establish expressibility in the bounded rule language
or behavior on unseen occurrences. Nevertheless, a cycle proves that
rule-only repair cannot satisfy the current evidence. After auditing the
certificates, we lift a cycle to concrete ranking arcs $p_i\to n_i$ and
the equality joins $n_i\sim_\phi p_{i+1}$, with cyclic indices.
This witness $W$ records the particular occurrences whose distinction
was lost, rather than only quotient-class names.

The LLM composes a finite catalogue $\mathcal F$ of typed structural
features. Define $d_{Wf}=1$ when $f$ separates at least one equality
join of $W$. With positive additive standalone work estimates $c_f$,
the repair master selects features by
\begin{equation}
 \begin{split}
 \min_{z_f\in\{0,1\}}\ &\sum_{f\in\mathcal F}c_fz_f,\\
 \text{subject to }&\sum_f d_{Wf}z_f\geq1
                   \quad\text{for every retained }W,\\
 &\sum_f z_f\leq K.
 \end{split}
 \label{eq:repair-cover}
\end{equation}
Every valid refinement must break a join in every such witness.
After each master, we append its selected features to the fixed base, replacing previous trial selections, and rebuild the \emph{full} quotient,
and add a surviving cycle as another constraint. Covering the original
simple quotient cycles alone is insufficient: a finer cycle can project
to a closed walk revisiting a coarse class. If no proposed feature covers
the new witness, synthesis expands the catalogue or reports an unresolved
repair at its budget limit.

\paragraph{Proposition 2 (finite-catalogue repair).}
If each master is solved globally and separation terminates with an
acyclic quotient, the selected features minimize the stated additive cost
over that catalogue, fixed evidence, and declared feature limit $K$.
\emph{Proof.} Every retained witness constraint is necessary, making the
master optimum a lower bound on the repair optimum. A final acyclic
quotient supplies feasibility, hence the reverse inequality.\hfill$\square$

With the feature limit part of the input, the generic explicit-catalogue problem is NP-hard by weighted set cover:
give each universe element a separate base class with one strict
self-loop pair, and let a candidate feature distinguish that pair exactly
when its source subset contains the element. Distinct base classes prevent
cross-element cycles. This reduction concerns the finite feature table;
it is not a hardness claim for every restricted graph language or a fixed constant feature limit. With fixed $K$, enumerating $O(|\mathcal F|^K)$ subsets is polynomial in catalogue size.
Without a cardinality constraint, weighted greedy gives an $H_m$
approximation for covering a fixed family of $m$ witnesses with additive
costs~\cite{chvatal1979greedy}; this guarantee does not apply to capped repair. A budgeted cover is accepted as a
representation repair only after the full DAG check; it provides no
future-consistency guarantee. With $N$ occurrences, $M$ requirements, and
$k$ features, vector hashing costs expected $O(Nk)$ and quotient construction
and cycle detection cost $O(N+M)$, excluding feature evaluation and
exact-number bit costs. Deterministic sorted traversal adds comparison work; master selection is combinatorial when $K$ varies.

\subsection{Typed Features and Compiled Residual Evaluation}
\label{sec:method:features}
The language distinguishes nodes, node sets, edge sets, and numbers.
Root and residual-neighborhood queries, set operations, induced edges,
weight aggregates, and bounded arithmetic compose deployable features.
For example,
\begin{equation}
 T_R(v)=\sum_{\{u,z\}\in E_\theta[N_R(v)]}\min(w_u,w_z)
 \label{eq:neighbor-structure}
\end{equation}
exposes conflicts among alternatives excluded by $v$, which degree and
neighbor-weight sums omit. It is a structural statistic, not a completion
bound: shared endpoints can appear in several terms.

Compilation shares identical typed subexpressions in a DAG and caches
root-independent expressions within their valid residual state. Recognized
degree, neighbor-weight, and neighborhood-edge aggregates use incremental
updates. Deleting $x$ subtracts one and $w_x$ from the first two quantities
for surviving neighbors $v$, and updates
\begin{equation}
 T(v)\leftarrow T(v)-
 \sum_{y\in N_R(v)\cap N_R(x)}\min(w_x,w_y).
 \label{eq:incremental-feature}
\end{equation}
Sequential deletion prevents double subtraction when both endpoints
disappear. Unrecognized expressions use the snapshot interpreter.
Initialization, intersections, updates, cache work, and scoring all enter
the work counter; dense-graph updates are not assumed constant-time.
Numerical semantics must preserve the feature interface used by
certification checks. Shared DAG cost is nonadditive, so the set-cover
approximation does not apply to actual deployment work.

\subsection{Joint Synthesis, Selection, and Frozen Deployment}
\label{sec:method:selection}
Algorithm~\ref{alg:joint-refinement} summarizes the loop. The LLM proposes
distinguishing features and rules over repaired interfaces. Whole feature--rule pairs compete by validation utility; the cheapest additive interface is a restricted-pool ablation. Type,
size, and finite-output checks enforce a closed execution language.
Every revision replays earlier reversal \emph{and} preservation evidence.
For consistency $s(P)$, complete-schedule validation quality $q(P)$,
and measured compiled work $c(P)$, selection uses
\begin{equation}
 J(P)=q(P)-\lambda\bigl(c(P)/c_{\rm ref}-1\bigr),
 \qquad s(P)\geq\tau,
 \label{eq:joint-utility}
\end{equation}
with declared $\lambda$, $\tau$, and baseline cost $c_{\rm ref}>0$.
Candidates must also have an acyclic observed quotient and valid interfaces.
Reversal and preservation violations are reported separately. A gate
below complete consistency is not described as satisfying all evidence.
If no valid candidate passes the gates, synthesis returns no eligible
program.

\begin{algorithm}[t]
\caption{Budgeted certified feature--rule synthesis}
\label{alg:joint-refinement}
\begin{algorithmic}[1]
\REQUIRE Training interventions, validation set, typed library, budgets
\STATE Initialize program archive and requirement set $\mathcal D$
\WHILE{discovery budget remains}
  \STATE Acquire anchored residual comparisons; append certified relations
  \STATE Audit and construct exact quotient $Q_\phi$ on $\mathcal D$
  \IF{$Q_\phi$ contains a cycle}
    \STATE Obtain typed features for concrete equality-join witnesses
    \STATE Solve cover; separate on full quotient until DAG or budget
  \ENDIF
  \STATE Propose and validate rules over repaired feature interfaces
  \STATE Replay $\mathcal D$; evaluate complete schedules and compiled cost
  \STATE Retain eligible feature--rule pairs by joint utility
\ENDWHILE
\STATE Freeze the selected representation, rule, and execution kernel
\end{algorithmic}
\end{algorithm}

Candidate generation comparisons use independent proposal batches for
witness-guided joint, free joint, and fixed-representation rule search,
with matched request and proposal counts and source evidence. Reusing one bank tests selection
gates, not guidance during generation. Discovery costs include proposals,
rejections, oracle attempts, and validation. The frozen program reads the
current graph on held-out instances and configurations, with no online LLM,
oracle, or saved-evidence access. Feasibility remains the kernel's invariant;
generalization and the quality--cost tradeoff are empirical questions.
