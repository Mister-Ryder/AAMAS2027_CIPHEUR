\section{Certified Representation--Rule Refinement}
\label{sec:method}

Certified conflicts direct offline typed feature--rule synthesis;
representability, schedule quality and cost checks precede freezing
(Figure~\ref{fig:algorithm}).

\subsection{Component-Cancelled Full-Residual Certificates}
\label{sec:method:certificates}
At boundary $B=(F,X)$, let $R=R_\theta(B)$,
$R_d=R\setminus(\{d\}\cup N_\theta(d))$, and $\mathcal C_d$ be the
connected components of $G_\theta[R_d]$, identified by exact vertex sets.
Additivity gives
\begin{equation}
 V_\theta(d\mid B)=w(F)+w_d+\sum_{C\in\mathcal C_d}\alpha_w(C),
 \label{eq:component-completion}
\end{equation}
where $\alpha_w(C)$ is the component's MWIS value. For two actions in the
same graph and boundary, set $\mathcal A=\mathcal C_a\setminus\mathcal C_b$
and $\mathcal B=\mathcal C_b\setminus\mathcal C_a$. Identical components cancel:
\begin{equation}
 \begin{split}
 \Delta_{ab}&=V_\theta(a\mid B)-V_\theta(b\mid B)\\
 &=w_a-w_b+\sum_{C\in\mathcal A}\alpha_w(C)
             -\sum_{C\in\mathcal B}\alpha_w(C).
 \end{split}
 \label{eq:cancelled-difference}
\end{equation}
Sound component intervals $[L_C,U_C]$ imply
\begin{equation}
 \begin{split}
 \underline\Delta_{ab}&=w_a-w_b+\sum_{\mathcal A}L_C-\sum_{\mathcal B}U_C,\\
 \overline\Delta_{ab}&=w_a-w_b+\sum_{\mathcal A}U_C-\sum_{\mathcal B}L_C.
 \end{split}
 \label{eq:difference-envelope}
\end{equation}
\paragraph{Lemma (sound cancellation).}
These endpoints enclose $\Delta_{ab}$.
\emph{Proof.} Independent component optima unite feasibly; shared terms
cancel and signed unmatched bounds enclose the remainder.\hfill$\square$

Matching is configuration-specific (Figure~\ref{fig:cancellation}).
Checked packings give lower bounds.
A sound $U_H$ for $H\subseteq C$ and verified clique partition
$\{K_j\}$ of $C\setminus H$ give
\begin{equation}
 U_C=U_H+\sum_j\max_{v\in K_j}w_v.
 \label{eq:clique-envelope}
\end{equation}
Relaxing cross-region edges proves soundness. Exact arithmetic, outward
rounding and stopped search retain enclosures;
exhausted calls return $[0,w(C)]$. Distinct partitions need not dominate.

Aligned configurations retain the same feasible actions and boundary.
For objective tolerance $\epsilon\geq0$, reversal requires
\begin{equation}
 \underline\Delta^{\theta_0}_{ab}>\epsilon,
 \qquad \overline\Delta^{\theta_1}_{ab}<-\epsilon,
 \label{eq:reversal-certificate}
\end{equation}
or exchanged roles; equal strict signs certify preservation. Other
intervals supply no strict label. Certified occurrences $x=(G_\theta,R,v)$ require
\begin{equation}
 h(\phi(x^+))>h(\phi(x^-)).
 \label{eq:strict-requirement}
\end{equation}

\subsection{Exact Quotients and Finite-Catalogue Repair}
\label{sec:method:repair}
The finite quotient $Q_\phi$ identifies exactly equal feature vectors and
adds arcs $[x^+]\to[x^-]$, including self-loops. Its nine base inputs are
reward, duration, degree, neighbor-weight sum/maximum, compatible-weight
sum, ground/satellite gaps and residual count. Diagnosis uses every declared field,
excludes IDs/splits, and audits omitted resource scalars before attributing
aliases to structure.

\paragraph{Proposition 1 (finite representability).}
An unrestricted deterministic pointwise scalar satisfies every observed
strict requirement iff $Q_\phi$ is acyclic.
\emph{Proof.} A cycle demands a strict decrease back to the same score.
Longest outgoing-path lengths on a finite DAG satisfy all arcs and scale
to any positive scoring margin.\hfill$\square$

Cycle witnesses comprise arcs $p_i\to n_i$ and joins
$n_i\sim_\phi p_{i+1}$. For finite typed catalogue $\mathcal F$,
$d_{Wf}=1$ if feature $f$ separates a join of witness $W$. Positive
standalone costs $c_f$ define the master
\begin{equation}
 \begin{split}
 \min_{z\in\{0,1\}^{|\mathcal F|}}\ &\sum_f c_fz_f,\\
 \text{s.t. }&\sum_f d_{Wf}z_f\geq1\quad\text{for each retained }W,\\
 &\sum_f z_f\leq K.
 \end{split}
 \label{eq:repair-cover}
\end{equation}
Trials replace additions, retaining the base; surviving full-quotient
cycles add cuts. Refined cycles can project to repeated coarse classes;
rechecking one witness is insufficient.

\paragraph{Proposition 2 (finite-catalogue repair).}
Globally solved masters followed by an acyclic full quotient minimize
additive cost for fixed catalogue, evidence and $K$.
\emph{Proof.} Necessary witness cuts give a lower bound on every valid
repair; the final DAG attains the master bound.\hfill$\square$

Arbitrary finite tables encode weighted set cover: element self-loops
are split by covering-subset features. Fixed $K$ allows $O(|\mathcal F|^K)$
trials; variable $K$ permits that reduction. Exhausted search or
uncovered witnesses stay unresolved. This guarantee concerns catalogue
repair; practical banks instead test each proposed interface for acyclicity.
Neither test proves bounded-rule fit or transfer.

\subsection{Typed Synthesis and Frozen Execution}
\label{sec:method:features}
LLM packets contain typed operations, graph/boundary examples, schedule
feedback and optional certified relations/equality joins. It proposes a typed
feature interface and deterministic scalar rule; tools enforce types,
size and finite outputs (Figure~\ref{fig:method}). Packing/cover summaries
and edge statistics, such as
\begin{equation}
 T_R(v)=\sum_{\{u,z\}\in E_\theta[N_R(v)]}\min(w_u,w_z),
 \label{eq:neighbor-structure}
\end{equation}
are scorer inputs, not conditional-completion certificates.
In Figure~\ref{fig:motivation}, neighborhood cover scoring gives
$(a,b):(8/26,8/20)\to(8/14,8/20)$; other actions can outrank both.

Shared expression DAGs and lazy inputs preserve defined finite reference
scores and deterministic ties. For deleted $x\in N_R(v)$, sequential updates use
\begin{equation}
 T(v)\leftarrow T(v)-\sum_{y\in N_R(v)\cap N_R(x)}\min(w_x,w_y),
 \label{eq:incremental-feature}
\end{equation}
using updated neighborhoods and exact accumulators. Nonincremental expressions
use the snapshot interpreter. A reviewed local-dependency heap refreshes
the neighbor frontier computed before deletion. Global or unreviewed
dependencies, including untaken branches, require full rescoring.
Compilation, initialization, updates and queries remain charged.
The kernel deploys the frozen program without LLM/oracle calls.

\subsection{Action Audits and Joint Selection}
\label{sec:method:actions}
At sampled reached boundaries, programs' argmax choices form finite
pool $\mathcal U_B$. For chosen $d\in\mathcal U_B$,
\begin{equation}
 \rho_{\mathcal U_B}(d)=
 \max_{u\in\mathcal U_B}[V_\theta(u\mid B)-V_\theta(d\mid B)].
 \label{eq:pool-regret}
\end{equation}
Maxima of zero and difference endpoints enclose this pool regret.
Report coverage/unknowns separately from counterfactual states.
Neither all-action regret nor complete-rollout loss is guaranteed.

\label{sec:method:selection}
TRAIN selection gates declared-interface acyclicity, then trades
complete reward against measured work:
\begin{equation}
 J(P)=q(P)-0.002\,[c(P)-1].
 \label{eq:joint-utility}
\end{equation}
Here $q,c$ average context reward/work ratios equally by family, against
fixed feasible references and positive degree work. Failed runs contribute
ratios $0,100$.
Measured shared-DAG cost differs from additive catalogue cost.
All pilot arms maximize $J$, break ties by original slot, and omit regret ties.
Empty eligible banks return no program.
Banks, evidence and selections freeze before fresh evaluation.
Kernel feasibility does not guarantee quality.
